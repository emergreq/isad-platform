# ISAD Hub — начальный прототип

React + Node.js + PostgreSQL. Это **не готовый к внедрению MVP**: реализованы только части утверждённого плана. Используйте исключительно демонстрационные данные.

## Локальный запуск

Нужны Docker и Docker Compose. Выполните в этой папке:

```sh
docker compose up --build -d
docker compose exec app npm run seed
```

Откройте http://localhost:5173. Демонстрационные учётные записи: `student@example.org`, `headman@example.org`, `teacher@example.org`, `coordinator@example.org`; пароль по умолчанию `demo-change-me`. Данные вымышленные. Seed рассчитан только на пустую базу. Остановка: `docker compose down`; добавление `-v` удалит базу.

При локальном запуске без Docker необходимы Node.js 22, npm и PostgreSQL. Установите зависимости через `npm install`, задайте `DATABASE_URL`, выполните `npm run migrate`, `npm run seed`, затем в разных терминалах `npm start` и `npm run dev`. Проверки: `npm test`, сборка: `npm run build`.

## Реализовано

Схема и миграция, учебные примеры, вход с хешированием паролей и серверными сессиями, ограниченные по группе/роли выборки занятий, заданий и материалов, просмотр личной посещаемости и задолженностей, каталог проектов, подача и атомарное принятие заявок через API. Интерфейс показывает основные списки и позволяет отметить ДЗ и подать заявку. Исключены отзывы и ML-лаборатория.

## Что необходимо закончить

- Назначения старост и периодов полномочий; администрирование учётных записей, групп и преподаваний.
- Создание и редактирование занятий и ДЗ в API и интерфейсе, история изменений и полноценный учёт зачисления.
- Ведение журнала, проверка преподавателем, выгрузка XLSX и журнал выгрузок.
- Создание задолженностей и слотов, запись на пересдачи, результаты и аудит состояния.
- Управление материалами, контактами и расписанием, исследование настоящего источника расписания.
- Интерфейсы создания проектов и позиций и обработки заявок; история решений; проверки безопасности и конкурентности на реальной PostgreSQL.
- Тесты API и прав, интеграционные и браузерные проверки, резервирование и восстановление; настройка HTTPS, защиты от перебора паролей, управления сессиями и секретами перед пилотом.

Доступ к материалам и расписанию сейчас основан на текущем членстве в группе, а не на полном учёте назначения и исторической даты; роль старосты пока не даёт прав на чужие записи. Данные не следует считать пригодными для реального использования.

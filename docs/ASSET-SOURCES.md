# Источники графики

## public/misis-logo.png

Знак Университета МИСИС в актуальной версии логотипа, опубликованной на Wikimedia Commons 20 июня 2023 года.

Страница файла: https://commons.wikimedia.org/wiki/File:Логотип_НИТУ_МИСиС.png

На странице указан официальный источник: https://misis.ru/university/rebranding/#brandbook

Оригинальный SVG со страницы университета найден по адресу https://misis.ru/files/-/5d3289e1e90b8ed16ce08f5aacb597af/MISIS_logoblock_main_rus_RGB-01_3.svg, но сайт не отвечал на загрузку; использована копия PNG с Wikimedia Commons.

Страница файла указывает атрибуцию ФГАОУ ВПО НИТУ «МИСиС», лицензию CC BY-SA 2.0 (https://creativecommons.org/licenses/by-sa/2.0/) и отметку PD-textlogo. Сведения приведены по странице источника. Сохранён исходный PNG без изменения пикселей; CSS показывает фрагмент с графическим знаком без текстового блока.

Декоративная иллюстрация в главном баннере — собственный SVG в client/src/main.jsx.

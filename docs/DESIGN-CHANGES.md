## Открыть и сохранить

Приложение: http://localhost:5173. Для обновления старой страницы — Ctrl+F5.

Изменения локальные, без коммита и push. Для сохранения после просмотра:

```powershell
cd "$env:USERPROFILE\Desktop\isad-platform"
git status
git diff
git add client/src/main.jsx client/src/style.css public/misis-logo.png docs/AI-ASSISTANT-PLAN.md docs/DESIGN-CHANGES.md docs/ASSET-SOURCES.md
git diff --cached
git commit -m "Redesign study space with cobalt theme and MISIS branding"
git push -u origin codex/pink-study-space
```

Затем создайте Pull Request из этой ветки в main и выполните merge после просмотра. Локальный compose.override.yaml с портом 55433 и старую инструкцию запуска добавлять не требуется.
